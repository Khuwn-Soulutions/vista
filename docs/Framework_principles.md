# Vista Principles: The Kingdom's Code

## Preamble

Vista is not a framework—it's a philosophy etched in Rust. Born from intent, it rebuilds Eden in code: reactive, cross-platform, divine. No HTML noise. No mortal compromises. Only pure, endless delight.

## Core Principles (The Pillars)

1. **Intent Over Syntax**

   - Declare _what_, not _how_. Widgets express purpose; reactivity flows naturally.
   - Example: `Button { reactivity: { ... } }` — intent manifests as UI.

2. **Reactivity as Consciousness**

   - Data: Widget-specific `Rx<T>` — `.value` reads truth, `.update()` evolves reality.
   - Actions: Extensible enums (`Action::Tap`, `Action::Swipe`) — gestures of will.
   - Auto-lifecycle: `Rx<ViewState>` manages creation to disposition, no manual toil.

3. **Platform Harmony**

   - Dual extensions: `interop!` for native code, `config` for data.
   - Web, iOS, Android — one Vista, many realms.

4. **Widget Sovereignty**

   - Each widget defines its data/actions. Container: simple. FlexibleContainer: reactive sizes.
   - SOLID obedience: Single responsibility per widget, open for extension.

5. **Delight in Efficiency**
   - Zero VDOM waste (Leptos signals). Typed safety. Cross-platform without bloat.
   - Humor: Like Eden's tree of life — desirable, but Vista won't crash your paradise.
