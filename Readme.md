# Vista Framework: A Hybrid cross-platform UI Library

## Introduction

Vista — a hybrid UI library for building cross-platform frontend applications with Rust

The vision is to create a comprehensive UI framework that combines the best aspects of existing libraries while introducing new paradigms for building user interfaces. Vista aims to be modular, extensible, and easy to use, allowing developers to create rich, interactive applications intuitively. In other words, the goal is to bring the best of frontend frameworks like Flutter, Juris, ReactNative and more together in Rust.

## Roadmap

The plan is to start with the web as the first target platform. While expanding to other platforms across mobile (e.g. iOS & Android), desktop (e.g. macOS & Windows), wearables, and beyond in the long term.
